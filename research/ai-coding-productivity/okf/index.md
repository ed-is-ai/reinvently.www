# AI Coding Productivity Evidence Base

OKF knowledge bundle for the systematic review [How Much Does AI Improve
Software Development Productivity?](https://reinvently.co.uk/blog/ai-coding-productivity-evidence/)
(181 source documents, 116 empirical studies, 46 productivity/delivery
effect estimates; search window 1 January 2022 – 31 July 2026). Each
concept below describes one dataset published alongside the article and
links to the sibling datasets it was built from or feeds into.

# Study-level registers

* [Evidence-weight register](evidence-weight-register.md) - one evidence-weight grade (high/moderate/low) per empirical study
* [Operating-model audit](operating-model-audit.md) - per-effect automation-model classification and plot status

# PRISMA search and screening

* [PRISMA bundle](prisma/) - search logs, raw record snapshots, and screening/eligibility registers for both the agentic-web/OpenAlex stream and the direct journal stream

# Risk-of-bias appraisal

* [Risk-of-bias bundle](risk-of-bias/) - study-level domain judgements and their aggregate totals
