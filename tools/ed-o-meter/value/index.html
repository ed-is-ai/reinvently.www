The value frontier #

Each dot is a model. Further left means cheaper; higher means a stronger rubric score. The gold line joins models that are not beaten by another model on both quality and cost. Those are the real trade-off choices in this dataset.

Pareto frontier

Lower-left is cheaper; upper-left is better value. Select a dot for its exact figures.

Select a model to see its rubric, cost, pass rate and value lens.
Use this as a trade-off view, not a new leaderboard score. Rubric is a single judge's quality assessment, not a universal intelligence measure. Cost/task is derived from the current source run; rows with a cost-denominator footnote should be compared with care.

How the value lens is calculated. The plot uses rubric quality out of 10 on the y-axis and USD cost per answering task on a logarithmic x-axis. The optional value figure shown on selection is rubric ÷ cost in US cents; it is deliberately secondary because a ratio can over-reward tiny cost differences.

Rubric scores, cost definitions, source-run details and the complete task results are documented on the main Ed-o-meter page. The current data source is 20260912T185245Z.
